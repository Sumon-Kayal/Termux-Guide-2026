# Code Compilation

## Code Compilation

**C/C++ Development:**
```bash
# Install compiler
pkg install clang

# Compile C program
clang program.c -o program

# Compile C++ program
clang++ program.cpp -o program

# Run
./program
```

**Rust Development:**
```bash
# Install Rust
pkg install rust

# Create new project
cargo new myproject
cd myproject

# Build project
cargo build

# Run project
cargo run
```
