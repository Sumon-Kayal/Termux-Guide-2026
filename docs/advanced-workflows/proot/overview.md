# Proot-Distro Overview

`proot-distro` runs full Linux distributions inside Termux without root.

```bash
proot-distro list
proot-distro install ubuntu
proot-distro install debian
proot-distro install fedora
proot-distro install archlinux
```

Ubuntu is covered in [Ubuntu](ubuntu.md). Desktop options are in [Desktop GUI (Termux:X11 & VNC)](../desktop-gui.md).
