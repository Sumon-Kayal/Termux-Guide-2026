# Contributing

Pull requests are welcome.

- Put new content under the matching part of `docs/` (`setup`, `tools`, `development`, `advanced-workflows`, `reference`); each page covers one topic and is listed in that part's `index.md`.
- Keep commands tested and copy-pasteable; mark anything that needs root.
- Scripts go in `scripts/`, runnable samples in `examples/`, images in `assets/`.
- Translations go in `translations/<locale>/` (for example `bn_IN`, `hi_IN`).
- Link to other pages with relative paths.
- Contributions are licensed under CC BY-SA 4.0, matching [LICENSE](LICENSE).
